# portfolio-manager-sample

ポートフォリオ管理 / 底値分析ダッシュボード（Streamlit）。

担保=配当4銘柄、被担保=日産自動車。担保増価による LTV / 配当推移、および
担保プールの底値ストレステストを可視化します。

> ⚠️ サンプルデータです。銘柄・株数・借入額などはすべてサンプル値で、投資助言ではありません。

## 機能

- **01 ポートフォリオ管理** — 保有銘柄の時価、確定売買の記録、LTV、しきい値（60/70/85%）進捗
- **02 配当 / 担保推移** — 配当成長・担保増価の時系列シミュレーション
- **03 底値分析** — 担保プールの底値ストレステスト / 銘柄別 底値マップ / 日産 買い増しラダー
- **04 日産自動車分析** — 決算・PSR・月次データは GitHub Pages（日産分析ノート）へリンク

## ポジション履歴

| 約定日 | 銘柄 | 区分 | 株数 | 代金 | 確定損益 | 代金の使途 |
|---|---|---|---|---|---|---|
| 2026-09-18 | 7203 トヨタ自動車 | 売却（成行） | 5,000 | 1,500万 | +70万 | 借入返済（8,000万 → 6,500万）|

トヨタ売却により担保プールは配当5銘柄→4銘柄。借入を同額返済したため LTV は
売却前相当 66.5% から 61.7% へ改善（現値ベース概算）。借入下限 5,000万は維持。

## 03 底値分析の考え方

「単一銘柄が◯円以下だった日数」ではなく、**このポートフォリオの借入と担保構成に
紐づけて**底値を評価する:

1. **担保プール 底値ストレステスト** — 現在の保有株数を過去の日足に当てはめて
   担保プールの合成日次系列を作り、現在の借入残高に対する LTV しきい値
   （60/70/85%）の抵触水準・抵触日数・最長連続日数・直近抵触日を出す。
   終値ベースの最大ドローダウンも併記。
2. **銘柄別 底値マップ** — 期間安値／高値と現値の位置関係、および
   「期間安値から +X% 以内で寄り付いた取引日数」（＝その水準を拾う機会が
   実際に何日あったか）。
3. **日産 買い増しラダー** — 年1,000万の買い増しペースを前提に、指値水準ごとの
   到達日数・到達率・最長連続取引日数・直近到達日と、1,000万で買える株数。

日数はすべて**取引日**ベース（暦日ではない）。判定にはその日の**安値**を使う。

> 着想のきっかけ: [mokusei02/stock-bottom-days-checker](https://github.com/mokusei02/stock-bottom-days-checker)
> （指定金額以下だった連続期間を数えるアプリ）。
> 本セクションは「担保プール × LTV しきい値」という別の問題設定に組み替えた
> 独自実装で、コードの流用はしていません。

## 株価データ

Yahoo Finance の chart API を使用（追加パッケージ不要、`requests` のみ）。

- **現値**: 5銘柄（`<コード>.T`）の `regularMarketPrice` を15分キャッシュ。
  取得失敗時は `dashboard.py` 内の `fallback_price` に自動フォールバック。
- **日足**: 同エンドポイントに `range` / `interval=1d` を付けて OHLC を取得、
  1時間キャッシュ。03 のトグルを ON にしたときだけ取得する。

Yahoo Finance は海外サーバーからでも日本株の当日終値を返すため、
Streamlit Community Cloud 上でも株価が反映されます。

## ローカル実行

```bash
pip install -r requirements.txt
streamlit run app.py
```

## テスト

底値分析の計算ロジックは `bottom_analysis.py` に純関数として切り出してあり、
ネットワーク非依存で検証できます。

```bash
python tests/test_bottom_analysis.py
```

## Streamlit Community Cloud へのデプロイ

1. [share.streamlit.io](https://share.streamlit.io) にGitHubアカウントでサインイン
2. **New app** → このリポジトリ / ブランチ `main` / Main file path `app.py` を指定
3. **Deploy** をクリック

テーマは Streamlit 標準（Settings メニューから Light / Dark を切り替え可能）。
底値分析のしきい値線は Light / Dark 両テーマで判読できる固定色を使い、
記号（🟢🟡🔴）とラベルを併記しているため、色だけに意味を持たせていません。
